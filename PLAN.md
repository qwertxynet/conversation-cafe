# Conversation café: the Arab majlis

Three timed 50-minute sessions about the culture of the Arab majlis, run as a presenter website.
This is a separate project from ألعاب المقهى and has no links to it.

## Decisions so far

| | |
|---|---|
| Arc | Guest → Host → Majlis (الضيف ← المضيف ← المجلس) |
| Students | 6–12, mixed and heritage levels |
| Arabic | فصحى only, with full tashkeel |
| Screen text | Arabic only. The teacher explains out loud. |
| Room | In person, and the seating can be moved into a majlis circle |
| Timer | Counts down each segment, then chimes and turns red at zero. The teacher clicks Next to move on. |
| Videos | YouTube players embedded in session 1 (the room needs internet). Arabic captions are switched on automatically, because the narration appears to be in English. |
| Levels | Prompts in three tiers (short, medium, open) plus deliberate mixed-level pairs |
| Coffee (session 2) | Real Arabic coffee, cups and dates. The teacher serves the first round as the host, then students take turns. |
| Extras | A hospitality proverb in each session, UNESCO heritage facts, a majlis seating diagram |
| Session 3 talk | Topic cards drawn from a mix: everyday life, news-style questions, and "where I'm from" |
| Closing | A short quiz on screen at the end of every session |
| Build | A timed presenter site. The lesson plans and handouts go inside it (format to be decided). |
| Publish | GitHub Pages once it's ready. Confirm before pushing. |

## Draft run of show

### Session 1: الضَّيْف (the guest)
| Time | Segment |
|---|---|
| 0–3 | Greetings at the door (السَّلَامُ عَلَيْكُمْ) and the proverb of the day |
| 3–28 | **Videos, half the session.** After each block (A, B, C), pairs get about 90 seconds to talk using a question card. |
| 28–38 | Greetings circle with three-tier cards |
| 38–45 | Sort what you should and shouldn't do in a majlis (mixed pairs) |
| 45–50 | Quiz on screen |

### Session 2: الْمُضِيف (the host)
| Time | Segment |
|---|---|
| 0–5 | Welcome, proverb, and a recap of session 1 |
| 5–12 | Phrases for hosting and being a guest (فصحى) |
| 12–27 | Coffee round following episode 5. The teacher hosts the first round, then students take turns as host. They practise: the youngest serves, starting with the eldest (or from the right), cups are taken with the right hand, the first cup is never refused, raise the cup for more and shake it when done, and the cup never goes on the floor. UNESCO note on Arabic coffee. |
| 27–45 | Gift-giving and dining scenario cards, with role-plays of mistakes |
| 45–50 | Quiz on screen |

### Session 3: الْمَجْلِس (the majlis)
| Time | Segment |
|---|---|
| 0–7 | Proverb, the seating diagram, and setting up the room as a majlis. UNESCO note on the majlis. |
| 7–10 | Hand out roles: host, elder, guest, newcomer |
| 10–42 | Two majlis circles. A new topic card is drawn every few minutes, and a "newcomer" arrives partway through. |
| 42–45 | Leave-taking phrases |
| 45–50 | Quiz on screen |
